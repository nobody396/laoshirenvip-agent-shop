# Product covers

These five WebP files are the existing customer-facing covers reused from the
老实人 VIP GMShop catalog. They were copied from our own live storefront; none
of the generated draft images from the catalog rewrite were used.

Mapping:

- `chatgpt-cover.webp`: all ChatGPT Go / Plus / Pro SKUs
- `codex-cover.webp`: Codex credit SKUs
- `claude-cover.webp`: Claude Pro / Max SKUs
- `x-cover.webp`: X Premium / Premium+ SKUs
- `grok-cover.webp`: SuperGrok SKUs
