# Dujiao-Next 下游对接

适用于已经拥有 Dujiao-Next 卡网的代理。没有卡网的代理应申请本平台白标子站。

## 开通

1. 在代理总站注册账号并完成邮箱验证。
2. 充值采购钱包；余额不足的 API 订单不会创建上游采购。
3. 在个人中心申请 API 凭证，等待管理员审核。
4. 审核通过后立即保存只展示一次的 API Secret。

## 下游配置

在下游站点进入“对接管理 → 连接管理 → 新增”：

| 字段 | 值 |
|---|---|
| 协议 | Dujiao OpenAPI |
| 站点地址 | 代理总站正式 HTTPS 地址 |
| API Key | 代理账户凭证 |
| API Secret | 代理账户凭证 |
| 回调地址 | 下游站点生成的 HTTPS 回调地址 |

保存后先执行“测试连接”，再同步商品并建立 SKU 映射。代理自行设置零售价；本站只按商品同步时和下单时的供货价快照扣采购钱包。

## 订单语义

- 下游必须为每笔订单生成永久唯一的 `downstream_order_no`。
- 超时或未知结果必须先查询原订单，禁止换订单号重复采购。
- 余额不足、商品下架或库存不足不会自动改用其他 SKU。
- 已交付订单不可取消；退款和售后以本站订单状态为准。
- 回调失败时使用 `GET /api/v1/upstream/orders/:id` 轮询补偿。

## 验收

正式销售前使用自有测试账号完成：连接、目录同步、一个测试 SKU、钱包扣款、交付回调、重复请求幂等和订单查询。测试通过不等于真钱生产路径已启用。
