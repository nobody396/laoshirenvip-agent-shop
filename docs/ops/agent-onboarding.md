# 代理开通与子站交付教程

## 收费与审核

- 正式代理开通费：¥99；首批内测可由管理员决定使用 ¥49。
- 开通费是代理资格、审核和子站配置服务费，不计入采购余额。
- 收到费用后仍需审核销售渠道、售后能力和风险；未通过审核应按约定退款。
- 第一阶段的开通费由管理员线下确认，不伪装成商品订单，也不自动绕过审核。

## 没有卡网的代理

1. 代理在总站注册账户并提交“申请分销商”。
2. 管理员确认开通费与审核资料，在“分销商管理”中批准申请。
3. 管理员分配唯一系统子域名，例如 `alice.shop.example.com`。
4. 代理进入分销中心设置站名、Logo、公告、客服和每个 SKU 的售价。
5. 终端客户在代理子站下单，使用总站统一支付渠道。
6. 总站按代理供货底价履约；成交价与供货底价之差进入代理待确认利润。
7. 确认期结束后利润变为可提现；代理提交申请，管理员线下转账后标记完成。

代理不需要服务器、域名、支付接口和上游账号。第一期只提供平台系统子域名，不承诺代理自带域名自动签证书。

## 已有卡网的代理

- Dujiao-Next：按 [Dujiao-Next 下游对接](../integration/dujiao-next.md) 配置。
- 异次元 ACG：按 [SharedStock 下游对接](../integration/acg-sharedstock.md) 配置。
- 两类下游都必须先充值采购余额；API 下单从余额扣供货价，不承担终端客户支付手续费。

## 手续费口径

- 子站终端客户使用总站支付时：商品金额与客户手续费附加分开快照；支付手续费附加不计代理利润。
- 代理自己向总站充值采购余额时：到账余额以实际确认金额为准，充值渠道手续费不得侵蚀平台商品毛利。
- 客户直接向代理转账时：代理再用自己的采购余额下单，不发生总站面向终端客户的支付手续费；代理自行承担收款和售后责任。

## 退款与提现

- 退款先退客户订单，再按同一订单快照冲回代理利润；禁止手工删流水。
- 利润确认期默认 7 天。
- 提现第一期为人工审核和线下转账：系统锁定余额，管理员实际付款后再标记完成。
- 提现不是自动支付宝或银行卡代付；未付款不得提前改为已完成。
