# 老实人 AI 伙伴验收清单

## 访客端

- [ ] 打开总站，站名显示“老实人 AI 伙伴”。
- [ ] 首批 14 个 SKU 名称、价格和库存正确。
- [ ] 注册、登录、商品详情、订单查询页面可用。
- [ ] 未配置真钱支付时不能误导客户已付款。

## 无卡网代理

- [ ] 测试用户提交代理申请，状态为待审核。
- [ ] 管理员批准并分配系统子域名。
- [ ] 子域名打开独立品牌页面，未知子域名不可串到总站。
- [ ] 代理能修改商品售价，但不能低于供货底价或超过最大加价限制。
- [ ] 代理能为自己的登录客户设置逐 SKU 固定专属价；其他客户、游客和其他子站仍显示普通零售价。
- [ ] 专属价在商品列表、详情、快速购买、订单预览、钱包扣款和订单快照中一致，且不能低于供货底价或高于普通零售价。
- [ ] 模拟支付后利润进入待确认；确认后可提现；退款生成负数冲回流水。

## 已有卡网代理

- [ ] Dujiao OpenAPI：连接、目录、余额扣款、幂等下单、订单查询、交付。
- [ ] ACG 新版 SharedStock：连接、items、item、inventory、valuation、trade。
- [ ] ACG 旧版 SharedStock：旧路径连接、目录、单品树形响应和库存。
- [ ] 相同 `request_no` 不重复扣款、不重复向 Aisou 采购。

## 上游与运维

- [ ] Aisou 连接测试和目录同步成功。
- [ ] 真实最小订单只用老板自有验收身份，确认购买、扣款和交付后才开放销售。
- [ ] PostgreSQL、Redis、应用和反向代理健康。
- [ ] 正式域名 wildcard DNS、TLS 与 Host 透传均实测。
- [ ] 支付手续费承担策略从生产配置读回。
- [ ] 代理承担手续费且商品差价不足时，只暂扣手续费缺口；余额不足不创建支付，失败/过期/取消幂等退回。
- [ ] 数据库、上传和配置备份完成一次恢复演练。

验收通过前保持真钱支付关闭。CI、镜像构建或健康检查通过，都不能替代真实支付和真实交付验收。
