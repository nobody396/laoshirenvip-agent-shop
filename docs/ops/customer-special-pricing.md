# 登录客户专属 SKU 价格

子站代理可以在“客户钱包”中为从自己子站注册的登录客户设置固定 SKU 专属价。

## 规则

- 仅登录客户生效；游客和其他客户继续使用普通零售价。
- 未设置的 SKU 继承代理普通零售价。
- 专属价必须满足：`平台结算底价 <= 专属价 <= 代理普通零售价`。
- 专属价不与主站会员价、促销价、优惠券或批发阶梯叠加。
- 支付手续费仍按子站支付配置处理；页面展示的预计毛利为扣手续费前毛利。
- 若底价或普通零售价变化导致专属价失效，前台隐藏该 SKU，下单接口拒绝旧价格，避免亏本或静默提价。

## 权威链路

1. 代理只能为 `registration_reseller_id` 指向自己的活跃客户设置价格。
2. 匿名商品目录保持公共缓存；登录商品目录使用鉴权接口并返回 `private, no-store`。
3. 订单预览和创建均按当前登录用户在服务端重新计算，不接受客户端传价。
4. 订单快照同时保存平台底价、代理普通零售价、客户成交价和专属价规则 ID。
5. 退款和代理利润继续以订单快照为准；后续改价不影响历史订单。

## 验收

- 客户 A 设置专属价后，商品列表、详情、快速购买、订单预览和订单成交价一致。
- 客户 B、游客和其他子站看不到客户 A 的专属价。
- 低于结算底价、高于普通零售价、跨代理客户和无效 SKU 均被拒绝。
- 钱包支付按专属价扣款；商户承担手续费时，仍需通过现有“售价覆盖手续费”校验。
- 删除专属价后，客户恢复普通零售价，历史订单快照不变。
