# 老实人VIP代理卡网 MVP

> 状态：本地开发立项，不授权购买服务器、配置生产域名、接入真钱支付或上线。
> 上游基线：Dujiao-Next `v1.4.7` (`47cc6207c6796ccfda0526a3708be39e1b59eba3`)，GPL-3.0。

## 目标

用一套 Dujiao-Next 部署为没有自有卡网的代理提供白标子站：

```text
Aisou / SharedStock
        ↓
老实人VIP代理总站
        ↓
代理子站（独立品牌和售价）
        ↓
终端客户
```

代理不部署服务器、不配置支付、不接触上游凭证。终端客户使用代理总站统一配置的支付渠道；总站统一采购和交付；代理差价进入独立分销利润账本并申请提现。

## 已确认的商业规则

- 正式代理开通价：`¥99`；首批内测价可设为 `¥49`。
- 代理申请必须审核，付费不自动绕过身份、渠道和风险审核。
- 每个代理获得一个平台系统子域名；第一期不开放代理自带域名。
- 代理可设置商品售价，但不得低于代理供货底价，也不得超过管理员配置的最大加价上限。
- 商品支付通道费不从平台供货利润中承担；启用客户手续费附加策略，商品价格与手续费分开快照。
- 代理利润为 `代理成交商品金额 - 代理供货底价`；支付附加费不计入代理利润。
- 利润自动记为待确认，确认期后转可提现；退款使用负数流水冲回；实际提现付款第一期由管理员线下转账并确认。
- 本人自买、关联账号、重复订单和退款套利不得产生利润。

## 系统职责

### Dujiao-Next 代理总站

- 代理申请、审核、禁用与恢复；
- 系统子域名、白标装修和代理商品定价；
- 终端客户订单和支付；
- 支付手续费附加与退款记录；
- 代理利润、退款扣减、确认期和提现；
- 调用上游适配器采购并接收交付。

### Aisou / SharedStock

- 商品目录、实时价格和库存；
- 实际采购；
- 卡密或兑换内容交付；
- 上游订单状态。

### VIP GMShop

继续服务现有零售业务，不进入代理订单链路，不与代理总站重复结算或共享订单状态。

## 第一阶段开发范围

1. 固定并保留 Dujiao-Next `v1.4.7` 上游基线和 GPL-3.0 许可。
2. 在 `internal/upstream` 增加 ACG SharedStock 协议 adapter，而不是把 Aisou 逻辑散落到采购、商品和 HTTP 调用方。
   - Dujiao 当前把上游 product/SKU ID 建模为 `uint`，SharedStock 的稳定标识是字符串 `shared_code`；不得直接哈希成整数。先增加可审计的稳定映射表，保存来源、SharedStock 数字商品 ID、`shared_code` 和规格名，再让采购订单引用该映射。
3. 扩展站点连接协议枚举、管理接口与前端选择项。
4. 实现连接测试、目录同步、单品查询、采购下单、订单查询、取消/不可取消映射和交付归一化。
5. 复用现有 procurement 队列、幂等下游订单号、回调和轮询补偿，不新增第二套采购状态机。
6. 只用合成凭证和测试响应完成单元/集成测试；不得在测试中写入真实 Aisou 密钥。
7. 本地创建一个测试代理、一个测试系统子域名和一个测试 SKU，跑通支付模拟、交付、利润、退款和提现状态。

## 上线前硬门槛

- 使用独立的代理业务上游账号/余额；若做不到，必须有明确订单前缀和跨系统余额对账。
- 使用 PostgreSQL + Redis，不以 SQLite 承载首批真实代理资金。
- 平台系统子域名必须完成 wildcard DNS 与 wildcard TLS 验证。
- 支付渠道、回调域名、手续费承担策略和退款手续费处理必须逐项读回。
- 用自有身份完成最小真实订单，不用代理或客户身份做发布测试。
- 代理订单、支付、上游采购、交付、利润和退款六方对账为零差异。
- 未获得老板针对该次发布的明确授权前，不购买服务器、不改 DNS、不部署、不启用真实支付。

## 非目标

- 第一阶段不支持代理自带域名；
- 不支持多级代理或下级抽成；
- 不支持代理自带支付渠道；
- 不支持自动支付宝/银行代付；
- 不把代理供货底价公开给普通访客；
- 不复制或共用 VIP GMShop 的生产支付、订单、利润或上游凭证记录。
